# Fibonacci Recursion Test

This project demonstrates the inefficiency of naive recursive Fibonacci.

It prints:
- Fibonacci numbers from 1 to 30  
- Execution time (nanoseconds)  
- Number of recursive calls used  

The results show that recursion leads to exponential growth in function calls:

O(2^n)

This makes it a poor choice for large inputs compared to iterative or memoized approaches.

## Purpose
Educational example to illustrate algorithmic complexity and why optimization matters.
